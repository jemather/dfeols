# Reference

Every public name is available as `dfeols.<name>`.

| Area | Names |
|---|---|
| [Fitting](fitting.md) | `fit`, `fit_glm`, `lpm_dthazard`, `Result` |
| [Data](data.md) | `prep`, `Dataset`, `plan`, `stack`, `Equation`, `Stacked`, `sample_groups` |
| [Execution](execution.md) | `executor`, `profile`, `SerialExecutor`, `DaskExecutor`, `build_plan`, `LockedError` |
| [Sessions](sessions.md) | `Session` |
| [Records](records.md) | `write_collection`, `Result.write_estimation` |

The command line (`dfeols plan`, `dfeols submit`, `dfeols session ...`) is described in the
user guide; `dfeols --help` and `dfeols <command> --help` list every option.
